# ENDEX CAN 橋接器 — BLE OTA 更新工具

用瀏覽器透過藍牙（BLE）更新 ENDEX CAN 橋接器（ESP32-H2）的韌體，不需要安裝任何軟體。

| 頁面 | 說明 |
|------|------|
| [ble_ota.html](ble_ota.html) | OTA 更新頁面：選擇 `.bin` 韌體檔 → 連線 `ENDEX_CAN_XXYY` 裝置 → 傳輸 → 自動驗證 |
| [ota_manual.html](ota_manual.html) | 操作手冊：更新步驟、燈號對照、疑難排解 |

## 使用方式

透過 GitHub Pages 開啟（網址需為 `https://`，Web Bluetooth 才能運作）：

- 更新頁面：`https://<帳號>.github.io/<repo>/`（或 `ble_ota.html`）
- 操作手冊：`https://<帳號>.github.io/<repo>/ota_manual.html`

## 瀏覽器需求

- 電腦或 Android 手機上的 **Chrome** 或 **Edge**
- iPhone / Safari 不支援 Web Bluetooth

韌體 `.bin` 檔案請向負責工程師取得。
